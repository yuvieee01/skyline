# Skyline: Day Mode / Night Mode

An interactive web project demonstrating a skyline transition between Day Mode and Night Mode with randomly lit windows.

## Features
- Toggle between daytime and night-time skyline views.
- Dynamic sun/moon and star displays.
- Randomized lit/unlit window simulation on buildings in night mode.

## Project Structure
- `skyline_night_mode_demo.html` - Main HTML markup
- `skyline_night_mode_demo.css` - Styles and visual transitions
- `skyline_night_mode_demo.js` - Toggle logic and window lighting randomization
